# 摸鱼相机 iOS 下一版制作要求

状态：效果图评审阶段，尚未确认制作新版功能 IPA。

## 正式应用图标

用户指定的原图：银黑色立体相机，蓝色大镜头中的白色小鱼，左上角黄色便签写“摸鱼”，右上角暖色闪光灯，黑色底。

已核对当前工程：scripts/generate_icon.swift 生成的是绿色底白色相机占位图，**不是用户指定图标**。

下一版必须使用用户提供的原图，适配为 1024×1024、无透明通道的 iOS AppIcon PNG；不得重新生成相似图或继续使用绿色占位图。
源图片文件需随正式制作时加入工程资源并保存在 GitHub，图标生成脚本应读取该原图而不是覆盖为占位图。
完成后检查编译后的图标资源和设备桌面显示，再声明替换完成。

## 待用户确认的功能效果图

- 原生应用内拍照、相册导入、GPS 当前地址获取、手动修改地址。
- 日期采用日历选择，时间采用时/分滚轮；星期自动更新。
- 马克/水印相机/真实时间三段文字可编辑，标识可拖动，留空隐藏。
- 时间、地址和标识真正合成到照片，并保存系统相册。
- 三种模式：沉浸拍摄、简约编辑、专业工作台。
- 录像支持开始、暂停、继续、结束；暂停不计入时长，继续接入同一条成品视频；结束后编辑水印、预览并导出。

用户要求：先看效果图，满意确认后才制作功能 IPA；本文件只记录设计，不表示功能已实现。
安装包名称字段继续为 ASCII MoyuCamera，内部界面使用中文，避免重现 SideStore appIdName 中文校验错误。
